# CAPRI v4 — Pixel Nights build brief

Improve Kenji Ku’s GitHub Pages 3D/isometric portfolio world using the supplied reference image as a stylistic guide, not as copied or extracted copyrighted game art. Retain a cozy explorable town, original expressive pixel-art chibi characters with jackets, colorful hairstyles, animated walking, moving tram, project buildings and clickable landmarks. Main character Kenji is playable with WASD, Shift to run, E to interact. Two original NPCs: Talia (pink hair) and D (blue jacket), without copying exact licensed character designs. Make the scenery small like a handheld game. Add an original generated synth/lo-fi soundtrack and short sound effects, strictly opt-in with accessible audio toggle. Do not autoplay. Keep GitHub Pages compatible: static HTML/CSS/JS and Three.js CDN, no build system or secrets.

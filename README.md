# Kenji Ku — Portfolio + CAPRI Neon District

**[Visit the portfolio](https://kukenji.github.io/)** · **[Play CAPRI Neon District](https://kukenji.github.io/world.html)**

An interactive cyberpunk pocket-city built in Three.js, with a pilotable hovercraft, flying traffic, animated chibi characters, moving elevated sky trains, and glowing project ads.

## Controls

- **W/A/S/D** or arrow keys: move
- **Space**: rise
- **Ctrl**: descend
- **Shift**: boost
- **Drag**: rotate view
- **Mobile**: touch directional / altitude controls

## GitHub Pages

Copy all website files (and the `assets/` folder) into the root of the `kukenji.github.io` repository, replacing existing matching files. Settings → Pages → Deploy from a branch → `main` → `/(root)`.

The world uses the Three.js CDN, so a network connection is needed. Screens and buildings are procedural Three.js geometry, not copyrighted game models. Project ads link to on-site information; SageAI also links to its public Devpost submission.

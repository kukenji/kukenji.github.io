# Kenji Ku — Portfolio & Kenji's World

**[Visit my portfolio](https://kukenji.github.io/)** · **[Explore Kenji's World](https://kukenji.github.io/world.html)**

I'm Kenji, a software engineer interested in systems, performance, and building useful, playful things. This repository hosts my professional website and **Kenji's World / CAPRI v4**, a tiny cozy cyberpunk-inspired 3D portfolio neighborhood.

## Explore the world

Walk with **WASD / arrow keys**, hold **Shift** to run, and press **E** near a glowing marker or character to interact. **M** toggles the minimap. Touch controls are provided for phones and tablets. The toggle in the upper right switches between evening and night lighting.

Explore six areas featuring my CORA capstone, SageAI hackathon, GIS mapping project, memory allocator, industry experience, and GitHub work. Meet the original residents Talia and D, watch the little tram, and explore.

## Technologies

HTML, CSS, JavaScript, Three.js (loaded as an ES module from jsDelivr), procedural 3D geometry and canvas textures. This project is a static website and is suitable for GitHub Pages. No build step or backend is required.

## Publish on GitHub Pages

Upload the contents of this folder (not the ZIP itself) to the root of `kukenji/kukenji.github.io`. If Pages is not yet enabled, go to **Settings → Pages → Deploy from branch → main → /(root)**. The links at the top will work after GitHub Pages deploys the files.

The game's people, art, geometry, and city layout are original stylizations created for this portfolio. They do not use extracted game assets. Project text is based on my described work and excludes confidential employer materials.
